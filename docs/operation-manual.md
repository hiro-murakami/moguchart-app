## 1. ログイン・ユーザー設定

### ログイン

- 画面右上の **「Login」** ボタンをクリックして Google アカウントでログインします。
- ログインしないと機能は利用できません。

### ゲストログイン

- ログイン画面で **「ゲストとしてログインする」** ボタンをクリックすると、Googleアカウントなしでゲストユーザーとして利用できます。
- ゲストユーザーで作成したデータは、およそ **24時間後に自動削除** されます。
- ログイン後にゲストデータの有効期限に関するアラートが表示されます。

### ユーザー設定

ログイン後、右上のアバターアイコンをクリックしてメニューを開きます。

| メニュー項目           | 説明                                                   |
| ---------------------- | ------------------------------------------------------ |
| **ユーザー設定**       | 表示名の変更ダイアログを開きます                       |
| **メールアドレス履歴** | 権限設定で使用するメールアドレスの補完候補を管理します |
| **リリースノート**     | アプリのリリースノートを表示します                     |
| **APIキー管理**        | REST API用のAPIキーの作成・一覧・無効化を管理します    |
| **ログアウト**         | ログアウトします                                       |

**ユーザー設定ダイアログ** では以下を確認・設定できます：

- **メールアドレス** — ログイン中のGoogleアカウントのメールアドレス（変更不可）
- **最終ログイン** — Googleアカウントの最終ログイン日時
- **表示名** — 他のユーザーに表示される名前

### メールアドレス履歴

権限設定で入力したメールアドレスは自動的に補完候補として保存されます。**「メールアドレス履歴」** ダイアログでは、保存済みの補完候補を一覧で確認・編集できます。

- 1行に1つのメールアドレスを入力するテキストエリア形式で管理します
- プロジェクト詳細ダイアログの権限タブにある **「メールアドレス履歴を管理」** ボタンからもアクセスできます

## 2. プロジェクト管理

### プロジェクト一覧を開く

- ガントチャート画面上部の **📋（リストアイコン）** をクリック
- または初期画面の **「プロジェクト一覧を開く」** ボタンをクリック

プロジェクト一覧ダイアログは左側に **「メイン」** / **「アーカイブ済」** の縦タブがあり、アーカイブしたプロジェクトと通常のプロジェクトを切り替えて表示できます。

### プロジェクトの検索

- プロジェクト一覧上部の **検索フィールド** にキーワードを入力すると、プロジェクト名・説明文でフィルタリングできます
- マッチした箇所はハイライト表示されます

### プロジェクトの新規作成

1. プロジェクト一覧ダイアログで **「新規作成」** ボタンをクリックするとドロップダウンメニューが表示されます
2. **「時間単位」** / **「日単位」** / **「月単位」** からモードを選択します（モードは作成後に変更できません）
3. プロジェクト詳細ダイアログが開きます
4. 必要な情報を入力して **「OK」** をクリック

### プロジェクト詳細の設定

プロジェクト詳細ダイアログには以下の **6つのタブ** があります：

#### 一般タブ

| 設定項目                       | 説明                                                                                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **モード**                     | ガントチャートの粒度（「時間単位」「日単位」「月単位」）。新規作成時に選択したモードがチップで表示されます（**作成後は変更不可**）                                                       |
| **プロジェクト名**             | プロジェクトの名前（必須）                                                                                                                                                               |
| **説明**                       | プロジェクトの説明文                                                                                                                                                                     |
| **開始日時 / 開始日 / 開始月** | ガントチャートの表示開始（時間単位モードでは日時選択、月単位モードでは月選択）                                                                                                           |
| **終了日時 / 終了日 / 終了月** | ガントチャートの表示終了（時間単位モードでは日時選択、月単位モードでは月選択）                                                                                                           |
| **期間スライド**               | 開始日・終了日・全タスク・マイルストーンをまとめて前後にずらす（[詳細](#15-期間スライド)）。既存プロジェクトでのみ表示されます                                                           |
| **スナップ単位**               | タスクの移動・リサイズ時にスナップする時間単位（**時間単位モード**：60 / 30 / 15 / 12 / 6 / 5分から選択、**日単位モード**：24 / 12 / 6 / 3時間から選択）。月単位モードでは表示されません |
| **一般公開**                   | ONにすると全ユーザーが閲覧可能に                                                                                                                                                         |
| **変更履歴の自動保存**         | 設定した間隔で変更前の状態を自動的にスナップショットとして保存（なし / 5分 〜 24時間）                                                                                                   |
| **自動履歴の保持期間**         | 自動保存されたスナップショットの保持期間（なし（無期限） / 7日 〜 90日）                                                                                                                 |

#### 編集オプションタブ

| 設定項目                           | 説明                                                                                                                                                                                            |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **行の入れ替えを禁止する**         | ONにすると、ガントチャート上でドラッグ＆ドロップによる行の並び替え操作を禁止します（デフォルトOFF）                                                                                             |
| **タスクの移動を横方向に限定する** | ONにすると、タスクバーを上下にドラッグして別の行へ移動する操作を禁止します（同一行内での日付移動のみ可能、デフォルトOFF）                                                                       |
| **進捗率管理を行う**               | ONにすると、タスクの進捗バー表示やドラッグ編集、進捗ラベル表示、タスク編集ダイアログでの進捗率入力を有効化します。OFFにすると進捗管理を行わないシンプルな画面になります（デフォルトON） |

#### 権限タブ

| 権限         | 説明                                     |
| ------------ | ---------------------------------------- |
| **オーナー** | プロジェクトに対する全権限を持つユーザー |
| **編集者**   | 閲覧・編集権限を持つユーザー             |
| **閲覧者**   | 閲覧のみ可能なユーザー                   |

- 権限にメールアドレスを入力する際、過去に入力したメールアドレスが補完候補として表示されます
- 権限タブ下部の **「メールアドレス履歴を管理」** ボタンから補完候補の一覧を編集できます

#### カラーパレットタブ

- タスクバーの色設定に使うカラーパレットを定義します
- **「パレット追加」** でパレットを追加し、**名前**・文字色・背景色を設定できます
- パレット名はタスク編集ダイアログのカラー選択時に表示され、識別しやすい名前を付けることができます
- パレット行をクリックすると詳細設定が展開され、以下の設定が可能です：

| 設定項目           | 説明                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| **パレット名**     | タスク編集ダイアログのカラー選択に表示される識別名                                                 |
| **文字色**         | タスクバー上のテキスト色                                                                           |
| **背景色**         | タスクバーの背景色                                                                                 |
| **パターンタイプ** | 背景に重ねるストライプ等のパターン（なし / diagonal-stripe など）                                  |
| **パターン色**     | パターンの色（パターンタイプ選択時に表示）                                                         |
| **枠線タイプ**     | タスクバーの枠線スタイル（なし / 実線(細) / 実線(太) / 破線(細) / 破線(太) / 点線(細) / 点線(太)） |
| **枠線色**         | 枠線の色（枠線タイプ選択時に表示）                                                                 |

#### ラベルタブ

- タスクや**行**に付与できるラベル（タグ）を定義します
- **「ラベル追加」** でラベルを追加し、名前と色を設定できます
- ここで定義したラベルは、タスク編集ダイアログおよび行編集ダイアログから選択できます

#### マイルストーンタブ

- ガントチャート上に縦線とバッジで表示されるマイルストーンを定義します
- **「マイルストーン追加」** でマイルストーンを追加し、名前・日付・色を設定できます
- 設定したマイルストーンはカレンダーヘッダーにバッジ、チャートエリアに縦線として表示されます
- マイルストーンにマウスオーバーすると、対応するバッジと縦線がハイライトされます

### プロジェクト一覧の操作

プロジェクト一覧には **プロジェクト名**・**説明**・**期間**・**モード（時間単位 / 日単位 / 月単位）**・**操作** の列が表示されます。

各行には以下のアクションボタンがあります：

**メインタブ（通常表示）：**

| ボタン              | 説明                                      | 必要な権限 |
| ------------------- | ----------------------------------------- | ---------- |
| ✏️ **編集**         | プロジェクト詳細の編集                    | オーナー   |
| 📋 **複製**         | プロジェクトのコピーを作成                | 全ロール   |
| 📥 **アーカイブ**   | プロジェクトをアーカイブ                  | オーナー   |
| 🗑️ **削除**         | プロジェクトの削除                        | オーナー   |
| ⬇️ **ダウンロード** | プロジェクトを ZIP ファイルでダウンロード | 全ロール   |

**アーカイブ済タブ：**

| ボタン                    | 説明                                      | 必要な権限 |
| ------------------------- | ----------------------------------------- | ---------- |
| 📤 **アーカイブから復元** | アーカイブ済みプロジェクトを元に戻す      | オーナー   |
| 🗑️ **削除**               | プロジェクトの完全削除                    | オーナー   |
| ⬇️ **ダウンロード**       | プロジェクトを ZIP ファイルでダウンロード | 全ロール   |

> アーカイブしたプロジェクトは「アーカイブ済」タブに移動します。アーカイブ操作後は「元に戻す」スナックバーが表示され、即座にアーカイブを取り消すことも可能です。

### プロジェクトの複製

1. プロジェクト一覧で **📋（複製ボタン）** をクリックすると、プロジェクト詳細ダイアログが **「プロジェクト複製」** モードで開きます。
2. **「一般」** タブで、以下の項目を設定できます：
   - **プロジェクト名** — 複製後のプロジェクト名を入力します（デフォルトは「＜元のプロジェクト名＞のコピー」）。
   - **開始日（開始月 / 開始日時）** — 変更すると、元のプロジェクト期間を維持したまま **終了日（終了月 / 終了日時）が自動調整** されます。すべてのタスクとマイルストーンの日付も、開始日の差分に応じて **自動的にスライド** されます。
   - **終了日** — 開始日の変更に連動して自動調整されます（変更不可）。
   - **進捗率をクリアする** — チェックを入れると、複製後のタスクの進捗率がリセットされます（デフォルトON）。
3. その他のタブ（編集オプション、権限、カラーパレット、ラベル、マイルストーン）では、複製元の設定がそのまま引き継がれます。プロジェクト詳細と同じUIで直接カスタマイズできます。
4. **「OK」** をクリックすると、複製が完了し自動的にそのプロジェクトが開かれます。

### バックアップからの復元

1. プロジェクト一覧で **「バックアップから復元」** ボタンをクリック
2. JSON ファイルまたは ZIP ファイルを選択
3. 同じ ID のプロジェクトが存在する場合、上書きまたは新規 ID での復元を選択できます

## 3. ガントチャートの基本操作

### 操作マニュアル

- 画面上部のヘッダーバーにある **📖（本アイコン）** をクリックすると、画面右側にドロワー形式で操作マニュアルが表示されます
- ドロワー上部の目次リンクをクリックすると、該当セクションにスクロールします

### ブラウザタブのタイトル

- プロジェクトを開くと、ブラウザのタブタイトルが **「MoguChart - ＜プロジェクト名＞」** に更新されます

### ダイアログのドラッグ移動

- すべてのダイアログは、**タイトルバーをドラッグ** することで画面内の任意の位置に移動できます
- タスク編集ダイアログやコメントダイアログなど、背面のガントチャートを確認しながら作業する際に便利です
- ダイアログを閉じて再度開いた場合、表示位置は自動的に中央にリセットされます

### 表示設定メニュー

画面上部右側の **⚙️（設定アイコン）** をクリックすると、表示設定メニューが開きます。

| 設定項目                   | 説明                                                                                                                                                                                                                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **非表示行を表示**         | 非表示設定された行を表示 / 非表示するスイッチ                                                                                                                                                                                                                                             |
| **現在時刻線を表示**       | 現在時刻を示す縦線の表示 / 非表示を切り替え                                                                                                                                                                                                                                               |
| **読み取り専用モード**     | ONにするとタスク・行の編集操作をすべて無効化します（オーナー / 編集者のみ表示）。プロジェクトごとに保存されます                                                                                                                                                                           |
| **クリティカルパスを表示** | ONにすると、依存関係グラフの最長チェーン（クリティカルパス）を自動検出し、該当するタスクバーと接続線を赤色でハイライト表示します。プロジェクトごとに保存されます                                                                                                                          |
| **ミニマップを表示**       | ONにすると、ガントチャート全体の鳥瞰プレビューを表示します。ミニマップ上でビューポートを移動したり、リサイズや不透明度調整、折りたたみが可能です。プロジェクトごとに保存されます（[詳細](#17-ミニマップ)）                                                                                |
| **ミニマップの不透明度**   | 「ミニマップを表示」がONの時に表示されます。スライダーでミニマップの不透明度（20%〜100%）を調整できます。プロジェクトごとに保存されます                                                                                                                                                   |
| **表示倍率**               | ＋ / − ボタンまたはスライダーでズームレベルを変更。**日単位モード**: px/日（20px/日 未満になると日付ヘッダーが週番号表示に切り替わります）、**月単位モード**: px/月、**時間単位モード**: px/時間。`Cmd`（Mac）/ `Ctrl`（Windows）+ マウスホイールでもズーム可能（[詳細](#16-ズーム操作)） |
| **バーの高さ**             | 極小 / 小 / 中 / 大 / 特大 から選択（5段階）                                                                                                                                                                                                                                              |
| **バーの影**               | タスクバーに付けるドロップシャドウの強さを なし / 小 / 中 / 大 から選択（4段階）                                                                                                                                                                                                          |
| **テーマ**                 | ライト / ダーク / システム設定に従う から選択                                                                                                                                                                                                                                             |

> 設定した表示倍率・バーの高さ・各スイッチの状態はプロジェクトごとにサーバーへ保存され、次回ログイン時にも復元されます。

### データの最新化

- **🔄（リフレッシュアイコン）** をクリックすると、サーバーから最新のデータを取得します

### データのエクスポート（CSV / Excel / ZIP / 画像 / PDF）

画面上部右側の **📤（エクスポートアイコン）** をクリックすると、エクスポートメニューが表示されます。

| メニュー項目             | 説明                                                                            |
| ------------------------ | ------------------------------------------------------------------------------- |
| **CSV でエクスポート**   | 表示中のデータをCSVファイルとしてダウンロード（BOM付きUTF-8）                   |
| **Excel でエクスポート** | 表示中のデータをExcelファイル（.xlsx）としてダウンロード                        |
| **ZIP でエクスポート**   | プロジェクトデータをZIPファイルとしてダウンロード（バックアップ復元に使用可能） |
| **PNG でエクスポート**   | ガントチャート全体を画像（PNG）としてダウンロード                               |
| **PDF でエクスポート**   | ガントチャート全体をPDFとしてダウンロード                                       |

エクスポートされるデータ（CSV / Excel）には、以下の列が含まれます：

| 列名         | 説明                                     |
| ------------ | ---------------------------------------- |
| **行名**     | タスクが所属する行の名前                 |
| **タスク名** | タスクの名前                             |
| **開始日**   | タスクの開始日（YYYY-MM-DD形式）         |
| **終了日**   | タスクの終了日（YYYY-MM-DD形式）         |
| **日数**     | タスクの期間（日数）                     |
| **ラベル**   | タスクに付与されたラベル（カンマ区切り） |
| **説明**     | タスクの説明文                           |

> ラベルフィルタが適用されている場合は、フィルタ対象外のタスクはエクスポートから除外されます。フィルタにより全タスクが除外された行もエクスポートされません。

## 4. タスク管理

### タスクの新規作成

1. ガントチャートの空白エリアを **右クリック** してコンテキストメニューを開きます
2. **「新しいタスクを作成」** を選択
3. タスク編集ダイアログが表示されるので、以下を入力します：
   - **タスク名**（必須）
   - **行**（配置する行）
   - **担当者**（メールアドレスを入力、後述）
   - **開始日 / 終了日**
   - **進捗率**（0〜100%、後述）
   - **色設定**（カラーパレットから選択、またはカスタム設定）
   - **ラベル**
   - **説明**
   - **ロック**（後述）
4. **「保存」** をクリック

### タスクの編集

- タスクバーを **ダブルクリック** するとタスク編集ダイアログが開きます
- または、タスクバーを **右クリック** → **「編集」** を選択

### タスクの移動・リサイズ

- タスクバーを **ドラッグ** すると日付を移動できます
- タスクバーを **上下にドラッグ** すると別の行へ移動できます（行をまたぐ移動）
  - ※プロジェクト設定で「タスクの移動を横方向に限定する」がONになっている場合は、行をまたぐ移動はできません
- タスクバーの端を **ドラッグ** すると開始日・終了日を変更できます
- ドラッグ操作中にマウスポインターがガントチャート領域外に出た場合、操作は自動的にキャンセルされて元の位置・日時に戻ります

### タスクの進捗率

タスク編集ダイアログの **「進捗率」** フィールド、またはガントチャート上の **ドラッグ操作** で、タスクの進捗状況を 0〜100% で設定・更新できます。

- **進捗バーの表示**: タスクバー上に進捗率に応じたプログレスバーおよび進捗ラベル（例: `50%`）が表示されます。
- **ドラッグによる進捗編集**: タスクバーにホバーすると進捗バーの右端に青いハンドルが表示されます。このハンドルを左右にドラッグすることで、ダイアログを開かずに直接マウス操作で進捗率を変更できます（5%刻みでスナップ）。ドラッグ中に `Escape` キーを押すと変更をキャンセルできます。
- **ミニマップへの反映**: ガントチャート画面右下のミニマップ上でも、タスクの進捗率が濃淡として自動反映されます。
- **進捗率管理の無効化**: プロジェクト設定（編集オプションタブ）で「進捗率管理を行う」をOFFに設定している場合は、進捗バー・ラベル・ハンドルおよびダイアログ内の進捗率入力フィールドが非表示になります。

> 進捗率はタスク編集ダイアログのクリアボタンで未設定（表示なし）に戻すこともできます。

### タスクの担当者設定

タスク編集ダイアログの **「担当者」** フィールドにメールアドレスを入力することで、タスクの担当者を割り当てることができます。

- **メールアドレスの補完**: 権限設定や過去に入力したメールアドレス履歴から候補がサジェスト表示されます。
- **担当者による進捗更新権限**: プロジェクトに対して「閲覧者（viewer）」権限しか持たないユーザーであっても、自身が担当者に設定されているタスクについては、**進捗率（progress）のみを直接ドラッグ編集またはダイアログから更新可能** です（タスク名や期間などの基本属性は閲覧専用として安全に保護されます）。
- **ツールチップ表示**: タスクバーにマウスオーバーすると、ツールチップ内に「担当: user@example.com」のバッジが表示されます。

### タスクのロック

タスク編集ダイアログの **「ロック」** スイッチをONにすると、そのタスクの移動・リサイズ・削除がすべて禁止されます。

> ロック中のタスクもダイアログからの編集は引き続き可能です。

### タスクの画像管理

タスクに画像を添付し、ガントチャート上で視覚的に確認できます。

#### 画像の追加・管理

1. タスクバーを **右クリック** → **「画像」** を選択すると画像管理ダイアログが開きます
2. 以下のいずれかの方法で画像を追加できます（複数ファイル対応）：
   - ダイアログ内のアップロードエリアに画像ファイルを **ドラッグ＆ドロップ**
   - **「ファイルを選択」** をクリックして画像ファイルを選択
   - スクリーンショット等をコピーした状態で `Ctrl+V`（Macは `⌘+V`）キーを押して **クリップボードから貼り付け**
3. 追加された画像は自動的に Firebase Storage にアップロードされ、サムネイル一覧に表示されます
4. 画像のサムネイルにマウスオーバーすると **×** ボタンが表示され、クリックで画像を削除できます
5. **「保存」** をクリックして変更を確定します

> 5MBを超える画像ファイルは、最大1920pxにリサイズし品質を自動調整して圧縮されます。手動でのリサイズは不要です。

#### 画像のプレビュー表示

- 画像が登録されたタスクバーにマウスオーバーすると、ツールチップ内に画像のサムネイルがプレビュー表示されます
- サムネイルをクリックするとライトボックスが開き、画像をオリジナルサイズで拡大表示できます
- 複数の画像が登録されている場合は、ライトボックス内のナビゲーションボタン（◀ / ▶）または **左右矢印キー** で画像を切り替えられます。現在の画像番号（例: 1 / 3）がライトボックス下部に表示されます
- ライトボックスの背景をクリック、または `Escape` キーで閉じます

> 画像は初回表示時にキャッシュされ、2回目以降は高速に表示されます。プロジェクト読み込み時にバックグラウンドでプリロードも行われます。

#### 画像の自動削除

- タスクを削除すると、そのタスクに関連付けられた画像が Firebase Storage から自動的に削除されます
- 行を削除した場合も、その行に含まれるすべてのタスクの画像が自動削除されます

### タスクのコピー＆ペースト

1. タスクバーを選択（クリック）した状態で `Cmd+C`（Mac）/ `Ctrl+C`（Windows）でコピー
2. `Cmd+V` / `Ctrl+V` でペースト
3. または、タスクバーを **右クリック** → **「コピー」** でコピー
4. チャートの空白エリアを **右クリック** → **「ペースト」** でペースト

> 複数のタスクを選択してまとめてコピー＆ペーストすることもできます。

### タスクの削除

- タスクバーを **右クリック** → **「削除」** を選択
- または、タスクバーを選択した状態で `Delete` / `Backspace` キーを押下
- 複数のタスクを選択した状態で削除すると、一括削除の確認ダイアログが表示されます

> 画像が登録されているタスクを削除すると、関連する画像も Firebase Storage から自動的に削除されます。

### タスクの依存関係

- タスクバーの両端に表示される接続ハンドル（丸いアイコン）を **ドラッグ＆ドロップ** して他のタスクに繋ぐことで、タスク間に依存関係の線を作成できます
- 依存関係の線（矢印）を **クリック** するとメニューが表示され、**「依存関係を削除」** を選択すると線を削除できます

### クリティカルパスの表示

- 表示設定メニュー（⚙️）で **「クリティカルパスを表示」** をONにすると、依存関係グラフの中で最も長いタスクチェーン（クリティカルパス）が自動的に検出され、該当するタスクバーと接続線が赤色でハイライト表示されます
- 依存関係に参加していない独立タスクはクリティカルパスの計算から除外されます

> クリティカルパスは、プロジェクト全体の所要時間を決定する最長の経路です。この経路上のタスクが遅延すると、プロジェクト全体の納期に影響します。

### タスクの選択（単一選択・複数選択・矩形範囲選択）

タスクバーを選択することで、移動・コピー・削除・キーボード操作などを実行できます。

#### 1. 単一選択
- タスクバーを **クリック** すると、そのタスクが選択状態（青い枠線）になります
- 別のタスクをクリックすると、以前の選択が解除され、新たにクリックしたタスクのみが選択されます

#### 2. 個別の複数選択（Ctrl / Cmd + クリック）
- `Ctrl`（Windows）または `Cmd`（Mac）キーを押しながらタスクバーをクリックすると、選択状態をトグル（追加 / 解除）できます
- 離れた位置にある複数のタスクをピンポイントでまとめて選択したい場合に便利です

#### 3. 矩形範囲選択（ラバーバンド選択）
- チャートの空白背景エリア（日付グリッド領域）でマウスを **ドラッグ** すると、半透明の青い矩形選択ボックスが表示されます
- 矩形と重なった（交差した）すべてのタスクバーがリアルタイムに一括選択されます
- ドラッグ操作中に画面端に近づくと、自動的にスクロール（オートスクロール）して画面外のタスクも巻き込んで選択できます
- マウスボタンを離すと選択が確定します

#### 4. 範囲選択の追加（Shift / Ctrl / Cmd + ドラッグ）
- `Shift`、`Ctrl`、または `Cmd` キーを押しながらチャート背景をドラッグすると、**現在の選択状態を保持したまま**、新たに囲んだ範囲内のタスクを追加選択（累積選択）できます

#### 5. 選択中のタスクに対する一括操作
複数のタスクを選択した状態で、以下の操作を一括して実行できます：
- **一括ドラッグ移動**: 選択中のいずれかのタスクバーをドラッグすると、選択された全タスクが相対的な位置関係を保ったまま一括して前後に移動します（選択タスクが同一行内にある場合は上下の行移動も可能）
- **キーボードでの一括移動**: `Shift + 左右矢印キー` で、選択中の全タスクを設定されたスナップ単位の刻みで前後に一括移動できます
- **一括コピー＆ペースト**: `Cmd+C` / `Ctrl+C` で選択中のタスクをまとめてコピーし、`Cmd+V` / `Ctrl+V` でペーストできます
- **一括削除**: `Delete` または `Backspace` キーを押すと、選択中の全タスクを一括削除する確認ダイアログが表示されます

#### 6. 選択の解除
- チャートの空白背景エリアを **クリック** するか、`Escape` キーを押すと、すべての選択がクリアされます

## 5. マーカー管理

マーカーは、ガントチャートの行上に配置するシンボル付きの目印です。マイルストーンとは異なり、行ごとに個別の日時を指定してピンポイントで配置できます。

### マーカーの新規作成

1. ガントチャートの空白エリアを **右クリック** してコンテキストメニューを開きます
2. **「新規マーカー」** を選択
3. マーカー編集ダイアログが表示されるので、以下を入力します：
   - **名前**（任意）— マーカーのラベルテキスト
   - **日時** — マーカーを配置する日時
   - **スタイル** — マーカーの表示スタイルを以下の3つから選択：
     - **◀ マーカー名** — 左向き三角形 + 右側にラベル（`anchor: start`）
     - **マーカー名 ▶** — 右向き三角形 + 左側にラベル（`anchor: end`）
     - **▼（改行）マーカー名** — 下向き三角形 + 下側にラベル（`anchor: center`）
   - **フォントサイズ** — ラベルとシンボルの大きさ（極小 / 小 / 中 / 大 / 特大 の5段階）
   - **色** — プリセットカラーから選択、またはカスタム色を指定
4. **「作成」** をクリック

### マーカーの編集

- マーカーを **ダブルクリック** するとマーカー編集ダイアログが開きます
- または、マーカーを **右クリック** → **「編集」** を選択

### マーカーの削除

- マーカーを **右クリック** → **「削除」** を選択
- または、マーカー編集ダイアログから削除操作が可能です

### マーカーの選択

- マーカーを操作中（ダブルクリックで編集ダイアログを開いた状態）は、対象マーカーにパルスアニメーションとグローエフェクトが適用され、どのマーカーを編集しているかが視覚的にわかります

### マーカー編集の破棄確認

- マーカー編集ダイアログで変更を加えた状態でダイアログを閉じようとすると、**変更を破棄するかどうかの確認ダイアログ** が表示されます
- 誤ってダイアログを閉じて編集内容を失うことを防ぎます

> マーカーはマイルストーンと異なり、行ごとに個別に配置される目印です。プロジェクト全体に適用されるマイルストーンはプロジェクト詳細のマイルストーンタブから管理します。

## 6. 行の操作

### 行の追加

- チャート左下の **＋（FABボタン）** をクリックすると行追加ダイアログが開きます
  1. **「追加する行数」** に 1〜10 の数値を入力（デフォルトは 1）
  2. **「追加」** ボタンをクリック（または `Enter` キー）
- または、行ヘッダーを **右クリック** → **「上に行を追加」** / **「下に行を追加」** を選択

### 行名のインライン編集

- 行ヘッダーを **Shift+クリック** すると、その場で行名を直接編集できます
- `Enter` で確定、`Esc` でキャンセル

### 行の詳細編集

- 行ヘッダーを **クリック** すると行編集ダイアログが開きます
- または、行ヘッダーを **右クリック** → **「行を編集」** を選択

行編集ダイアログでは以下を設定できます：

| 設定項目   | 説明                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| **行名**   | 行の名前（必須）                                                       |
| **ラベル** | 行に付与するラベル（プロジェクトで定義したラベルから選択、複数設定可） |
| **説明**   | 行の説明文                                                             |

### 行ヘッダーのツールチップ

- 行ヘッダーにマウスオーバーすると、行の詳細情報をツールチップで確認できます
- ツールチップには以下の情報が表示されます：
  - **行名** — 行の名前
  - **ラベル** — 行に設定されているラベル
  - **説明** — 行の説明文（150文字まで表示）
  - **タスク数** — 行に含まれるタスクの件数
  - **コメント数** — 行に付けられたコメントの件数

### 行の並び替え

- 行ヘッダーを **ドラッグ＆ドロップ** して順序を変更できます
- ※プロジェクト設定で「行の入れ替えを禁止する」がONになっている場合は、ドラッグによる並び替えはできません

### 行の表示/非表示

- 行ヘッダーを **右クリック** → **「行を非表示」** / **「行を表示」** を選択
- 複数の行を選択した状態で操作すると、まとめて表示/非表示を切り替えられます

### 行の削除

- 行ヘッダーを **右クリック** → **「行を削除」** を選択
- 複数の行を選択した状態で操作すると、まとめて削除できます

### 行の画像管理

行に画像を添付し、行ヘッダー上で視覚的に確認できます。

#### 画像の追加・管理

1. 行ヘッダーを **右クリック** → **「画像」** を選択すると画像管理ダイアログが開きます
2. 以下のいずれかの方法で画像を追加できます（複数ファイル対応）：
   - ダイアログ内のアップロードエリアに画像ファイルを **ドラッグ＆ドロップ**
   - **「ファイルを選択」** をクリックして画像ファイルを選択
   - スクリーンショット等をコピーした状態で `Ctrl+V`（Macは `⌘+V`）キーを押して **クリップボードから貼り付け**
3. 追加された画像は自動的に Firebase Storage にアップロードされ、サムネイル一覧に表示されます
4. 画像のサムネイルにマウスオーバーすると **×** ボタンが表示され、クリックで画像を削除できます
5. **「保存」** をクリックして変更を確定します

> 画像の追加・圧縮・削除の仕組みはタスク画像管理と同じです。

#### 行ヘッダーのサムネイル表示

- 画像が登録された行は、行ヘッダーの右端に小さなサムネイルが表示されます
- サムネイルのサイズはバーの高さ設定に連動します
- 複数の画像が登録されている場合は、サムネイル右下に画像枚数のバッジが表示されます

#### 画像のプレビュー・ライトボックス

- サムネイルにマウスオーバーすると、ポップアップで画像のプレビューが表示されます
- 複数画像の場合はナビゲーションボタン（◀ / ▶）で画像を切り替えられます
- プレビュー画像をクリックするとライトボックスが開き、画像をオリジナルサイズで拡大表示できます

> 行を削除した場合、行に関連付けられた画像も Firebase Storage から自動的に削除されます。

### 行ヘッダーの幅調整

- 行ヘッダーの右端をドラッグして幅を調整できます

## 8. 検索・フィルタ

### フリーワード検索

- 画面上部の **「フリーワード検索」** テキストフィールドにキーワードを入力すると、マッチするタスクがハイライトされます
- **「行も検索」** チェックボックスをONにすると、行名も検索対象になります

### ラベルフィルタ（タスク）

- 画面上部の **ラベルフィルタ** アイコンをクリックして、表示するタスクラベルを選択できます
- フィルタの候補は、実際のタスクに付与されているラベルから自動的に収集されます（未使用のラベルは表示されません）
- **「全選択」** / **「全解除」** のショートカットも利用可能です
- フィルタが適用されている場合、対象外のラベルを持つタスクは非表示になります

### 行ラベルフィルタ

- ガントチャート左上の **コーナーメニュー** から行ラベルでフィルタリングできます
- フィルタの候補は、実際の行に付与されているラベルから自動的に収集されます（未使用のラベルは表示されません）
- 行にラベルが設定されていない場合はフィルタは表示されません
- 複数のラベルで絞り込むと、選択したラベルのうち**いずれか**が設定されている行が表示されます

## 9. コメント機能

コメントは **タスク**、**行**、**プロジェクト** の3つの対象に対して追加できます。

### タスクへのコメント

- タスクバーを **右クリック** → **「コメント」** を選択するとコメントダイアログが開きます
- コメントが付いているタスクは、コメント件数が表示されます

### 行へのコメント

- 行ヘッダーを **右クリック** → **「行にコメント」** を選択するとコメントダイアログが開きます

### プロジェクトへのコメント（コメントサイドバー）

プロジェクトコメントは、画面右端の **コメントサイドバー** で管理します。

- サイドバーの **タイトルバー** をクリックすると開閉します
- 開いているときのサイドバー幅は右端をドラッグして調整できます（最小220px）
- 開閉状態と幅はプロジェクトごとに保存されます

> チャートエリアはコメントサイドバーの幅に合わせて自動的にリサイズされます。

また、以下のボタンからもコメントダイアログへアクセスできます：

- プロジェクト名の横にある **💬（コメントアイコン）** をクリックするとコメントダイアログが開きます
- コメントがある場合はアイコンの横にコメント件数が表示されます
- コメントアイコンにマウスオーバーすると、直近のコメントがツールチップで表示されます

### コメントダイアログの操作

| 操作             | 説明                                                                                 | 必要な権限        |
| ---------------- | ------------------------------------------------------------------------------------ | ----------------- |
| **コメント入力** | テキストエリアにコメントを入力し、送信ボタンまたは `Cmd+Enter` / `Ctrl+Enter` で送信 | オーナー / 編集者 |
| **コメント閲覧** | コメント一覧を閲覧                                                                   | 全ロール          |
| **コメント削除** | 自分のコメントを削除（オーナーは全コメントを削除可能）                               | オーナー / 編集者 |

## 13. 時間単位モード

時間単位モードは、プロジェクト作成時に選択する粒度設定です。1日未満の細かいスケジュール管理に適しています。

### 日単位モードとの違い

| 項目                             | 日単位モード                | 時間単位モード                      |
| -------------------------------- | --------------------------- | ----------------------------------- |
| 開始・終了の設定                 | 日付で指定                  | 日時（分単位）で指定                |
| タスクの開始・終了設定           | 日付で指定                  | 日時で指定                          |
| 表示倍率の単位                   | px/日                       | px/時間                             |
| カレンダーヘッダー               | 日・週                      | 時間・日                            |
| スナップ単位の設定               | 24 / 12 / 6 / 3時間から選択 | 60 / 30 / 15 / 12 / 6 / 5分から選択 |
| プロジェクト複製時の日付スライド | 日単位でスライド            | ミリ秒単位でスライド                |

### スナップ単位

時間単位モードでは、タスクの移動・リサイズ時にスナップする時間の刻みを設定できます。プロジェクト詳細ダイアログの「スナップ単位」で選択します（デフォルトは60分）。

> モードはプロジェクト新規作成時のみ選択可能で、作成後の変更はできません。

## 14. 月単位モード

月単位モードは、プロジェクト作成時に選択する粒度設定です。月をまたぐ長期プロジェクトの管理に適しています。

### 日単位モードとの違い

| 項目                             | 日単位モード     | 月単位モード     |
| -------------------------------- | ---------------- | ---------------- |
| 開始・終了の設定                 | 日付で指定       | 月で指定         |
| タスクの開始・終了設定           | 日付で指定       | 月で指定         |
| 表示倍率の単位                   | px/日            | px/月            |
| カレンダーヘッダー               | 日・週           | 月・年           |
| 期間の上限                       | 24ヶ月           | 100年            |
| プロジェクト複製時の日付スライド | 日単位でスライド | 月単位でスライド |

> モードはプロジェクト新規作成時のみ選択可能で、作成後の変更はできません。

## 15. 期間スライド

プロジェクト全体のスケジュールを前後にまとめてずらす機能です。個々のタスクを手作業で移動する必要がなく、プロジェクト開始日の変更に伴う一括更新が簡単に行えます。

### 期間スライドを開く

1. 画面上部の **✏️（プロジェクト詳細アイコン）** をクリック（オーナーのみ）
2. プロジェクト詳細ダイアログ **一般タブ** に表示される **「期間スライド」** ボタンをクリック
3. 「期間スライド」ダイアログが開きます

### 操作手順

| 入力項目                              | 説明                                                                          |
| ------------------------------------- | ----------------------------------------------------------------------------- |
| **新しい開始日（開始月 / 開始日時）** | スライド後の新しいプロジェクト開始日を指定します                              |
| **終了日（自動計算・変更不可）**      | 開始日の変更差分に応じて自動計算されます                                      |
| **進捗率をクリアする**                | ONにするとスライド後にすべてのタスクの進捗率をリセットします（デフォルトOFF） |

**「OK」** をクリックすると、以下がすべてスライドされます：

- プロジェクトの表示開始日・表示終了日
- すべてのタスクの開始日・終了日
- すべてのマイルストーンの日付

> 差分が0（開始日に変更がない）の場合は何も変更されません。

> 期間スライドは **オーナー権限** が必要です。

## 16. ズーム操作

ガントチャートの表示倍率を、マウスホイールを使って直感的に変更できます。

### マウスホイールによるズーム

- `Cmd`（Mac）/ `Ctrl`（Windows）を押しながら **マウスホイールを上に回す** と **ズームイン**（拡大）します
- `Cmd`（Mac）/ `Ctrl`（Windows）を押しながら **マウスホイールを下に回す** と **ズームアウト**（縮小）します
- ズームレベルは表示設定メニューのスライダーと連動しており、ホイール操作による変更がスライダーにも即座に反映されます

### ズームの範囲

各モードごとにズームの最小値・最大値が設定されています：

| モード             | ズーム単位 | 最小値 | 最大値 | ステップ |
| ------------------ | ---------- | -----: | -----: | -------: |
| **日単位モード**   | px/日      |     10 |     80 |        5 |
| **月単位モード**   | px/月      |     10 |     80 |        5 |
| **時間単位モード** | px/時間    |     50 |    300 |       50 |

> ズームレベルはプロジェクトごとにサーバーへ保存され、次回ログイン時にも復元されます。

## 17. ミニマップ

ガントチャート全体の縮小プレビュー（鳥瞰図）を表示し、プロジェクト全体の進捗状況やタスク・マイルストーンの配置を俯瞰しながら素早くナビゲーションできる機能です。

### ミニマップの表示 / 非表示

- 画面上部右側の **⚙️（設定アイコン）** をクリックし、**「ミニマップを表示」** スイッチで表示 / 非表示を切り替えます
- 表示状態はプロジェクトごとにサーバーへ自動保存され、次回開いた際にも引き継がれます

### ビューポートの移動（スクロール同期）

- ミニマップ内の **半透明の枠（ビューポート）** は、現在画面に表示されているガントチャートの表示領域を示しています
- ビューポート枠を **ドラッグ** するか、ミニマップ内の任意の位置を **クリック** することで、ガントチャートの表示位置（スクロール）を素早く移動できます

### ミニマップの配置とリサイズ

- ミニマップはガントチャート画面の **右下** に固定配置されます
- ミニマップの四隅や四辺（リサイズハンドル）を **ドラッグ** することで、チャート全体のアスペクト比を維持したままサイズ（幅・高さ）を拡大・縮小できます
- 変更したサイズ（幅）はプロジェクトごとにサーバーへ自動保存され、次回開いた際にも復元されます

### ミニマップの透過率（不透明度）の調整

- 画面上部右側の **⚙️（設定アイコン）** を開き、「ミニマップを表示」がONの時に表示される **「ミニマップの不透明度」** スライダーで、透過率を 20% 〜 100% の範囲で調整できます
- ミニマップを半透明にすることで、背面のガントチャートのタスクを確認しながら作業できます
- ミニマップ上にマウスカーソルを合わせる（ホバー）か、リサイズ操作を行っている間は、自動的に不透明度が 100% になり視認性が向上します
- 設定した不透明度はプロジェクトごとにサーバーへ自動保存されます

### ミニマップの折りたたみ（最小化 / 展開）

- ミニマップ右上にある **「×」（折りたたみ）ボタン** をクリックすると、右下にコンパクトな地図アイコンとして最小化されます
- 最小化されたアイコンをクリックすると、元のサイズで再展開されます
- 折りたたみ状態（展開 / 最小化）はプロジェクトごとにサーバーへ自動保存され、次回開いた際にも維持されます

### ミニマップの設定の永続化

ミニマップに関する以下の設定は、プロジェクトごとにサーバーへ自動保存されます：

- **表示状態（表示 / 非表示）**
- **幅（サイズ）**
- **不透明度（透過率）**
- **折りたたみ状態（展開 / 最小化）**

## 18. REST API連携

MoguChartは外部アプリケーションからデータにアクセスするためのREST APIを提供しています。

### 概要

- REST APIを使って、プロジェクト・行・タスク・コメント・スナップショットのCRUD操作が可能です
- 公開プロジェクト用のエンドポイント（認証不要）も提供されています
- すべてのエンドポイント（ヘルスチェックを除く）は `X-API-Key` ヘッダーによるAPIキー認証が必要です
- レスポンスはJSON形式で統一されています

### APIキー認証

APIキーには2つのスコープがあります：

| スコープ       | 説明                                         |
| -------------- | -------------------------------------------- |
| **read**       | 読み取り専用。データの取得のみ可能           |
| **read-write** | 読み書き可能。データの作成・更新・削除が可能 |

### WebUIでのAPIキー管理

ブラウザ上のアプリケーションからAPIキーを管理できます。

1. 画面右上のアバターアイコンをクリックしてメニューを開きます
2. **「APIキー管理」** を選択するとAPIキー管理ダイアログが開きます

#### APIキーの作成

1. ダイアログ下部の **「新しいキーを作成」** ボタンをクリック
2. **キーの名前**（用途の識別用。例: 「CI/CD連携用」）を入力
3. **スコープ**（読み書き / 読み取り専用）を選択
4. **「作成」** をクリック
5. 作成直後にフルキーが表示されます。**📋（コピーボタン）** でクリップボードにコピーして安全な場所に保存してください

> ⚠️ フルキーは作成直後の1回のみ表示されます。ダイアログを閉じると二度と確認できません。

#### APIキーの一覧

- キー名、スコープ、最終使用日時、状態（有効/無効）が確認できます
- キー文字列は先頭8文字のみ表示され、残りはマスクされます

#### APIキーの無効化

1. 無効化したいキーの **🗑️（削除ボタン）** をクリック
2. 確認ダイアログで **「無効化」** をクリック

> 無効化されたAPIキーは一覧に「無効」ラベル付きで表示され続けますが、このキーを使用したAPIアクセスはすべて拒否されます。

### 主なエンドポイント

| リソース             | 操作                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **プロジェクト**     | 一覧取得（`GET /projects`）、単体取得（`GET /projects/:id`）、作成（`POST /projects`）、更新（`PUT /projects/:id`）、削除（`DELETE /projects/:id`）、複製（`POST /projects/:id/duplicate`）、チャートデータ取得（`GET /projects/:id/chart`）、行データ取得（`GET /projects/:id/rows`）、JSON/ZIPエクスポート（`GET /projects/:id/json`, `GET /projects/:id/zip`）、復元（`POST /projects/restore`, `POST /projects/:id/restore`） |
| **行**               | 作成（`POST /rows`）、更新（`PUT /rows`, `PUT /rows/:id`）、削除（`DELETE /rows`, `DELETE /rows/:id`）、並び順更新（`PUT /rows/order`）                                                                                                                                                                                                                                                                                           |
| **タスク**           | 作成/更新（`POST /tasks`, `PUT /tasks`, `PUT /tasks/:id`）、削除（`DELETE /tasks`, `DELETE /tasks/:id`）、タスクコメント管理（`GET /tasks/:id/comments`, `POST /tasks/:id/comments`, `DELETE /tasks/:id/comments/:commentId`）                                                                                                                                                                                                    |
| **コメント**         | 一覧取得（`GET /comments`）、作成/更新（`POST /comments`）、削除（`DELETE /comments/:id`）、タスクコメント操作（`GET /comments/tasks/:taskId/comments`, `DELETE /comments/tasks/comments/:commentId`）                                                                                                                                                                                                                            |
| **スナップショット** | 一覧取得（`GET /projects/:id/snapshots`）、作成（`POST /projects/:id/snapshots`）、取得（`GET /projects/:id/snapshots/:name`）、URL取得（`GET /projects/:id/snapshots/:name/url`）、削除（`DELETE /projects/:id/snapshots/:name`）                                                                                                                                                                                                |
| **ユーザー**         | ユーザー情報取得（`GET /user`）、更新（`PUT /user`）                                                                                                                                                                                                                                                                                                                                                                              |
| **APIキー**          | 一覧取得（`GET /api-keys`）、新規発行（`POST /api-keys`）、無効化（`DELETE /api-keys/:id`）                                                                                                                                                                                                                                                                                                                                       |
| **公開プロジェクト** | プロジェクト情報取得（`GET /public/projects/:id`）、ガントチャートデータ取得（`GET /public/projects/:id/gantt`）（認証不要）                                                                                                                                                                                                                                                                                                      |

### レートリミット

REST APIにはAPIキー単位のレートリミットが設定されています。過剰なリクエストからサービスを保護するための仕組みです。

#### 制限値

| 項目                 | 値                                                     |
| -------------------- | ------------------------------------------------------ |
| **最大リクエスト数** | 60 リクエスト / 1分                                    |
| **アルゴリズム**     | スライディングウィンドウカウンター                     |
| **識別単位**         | APIキーまたはFirebase IDトークン（メールアドレス）ごと |

#### レスポンスヘッダー

すべての認証済みAPIレスポンスには以下のレートリミットヘッダーが付与されます：

| ヘッダー              | 説明                                                     |
| --------------------- | -------------------------------------------------------- |
| `RateLimit-Limit`     | ウィンドウ内の最大リクエスト数（60）                     |
| `RateLimit-Remaining` | ウィンドウ内の残りリクエスト数                           |
| `RateLimit-Reset`     | 現在のウィンドウがリセットされるUNIXタイムスタンプ（秒） |

#### レートリミット超過時

制限を超過すると `429 Too Many Requests` ステータスが返されます：

```json
{
  "status": "failed",
  "message": "Too many requests. Please try again later.",
  "retryAfter": 15
}
```

レスポンスには `Retry-After` ヘッダー（秒数）が付与されます。この秒数だけ待ってからリクエストを再試行してください。

#### レートリミットの適用範囲

| エンドポイント                           | レートリミット |
| ---------------------------------------- | -------------- |
| `GET /api/v1/health`                     | ❌ 適用なし    |
| `/api/v1/public/*`（公開プロジェクト用） | ❌ 適用なし    |
| `/api/v1/*`（認証必須エンドポイント）    | ✅ 適用あり    |

### レスポンス形式

すべてのレスポンスは以下の統一形式で返されます：

```json
{
  "status": "succeeded" | "failed",
  "message": "（任意）",
  "data": ...
}
```

> 詳細なAPI仕様は OpenAPI仕様書（`docs/openapi.yaml`）を参照してください。

## 19. Google Apps Script連携

REST APIと連携して、ガントチャートのデータをGoogle Spreadsheetで表示・管理するためのGoogle Apps Script（GAS）テンプレートが提供されています。

### セットアップ手順

1. [Google Spreadsheet](https://sheets.google.com) で新しいスプレッドシートを作成
2. 「拡張機能」>「Apps Script」を開く
3. テンプレートの4つのファイル（`Config.gs`、`MoguchartApi.gs`、`SheetFunctions.gs`、`Menu.gs`）のコードを貼り付け
4. スプレッドシートに戻りページをリロード
5. メニューバーの「🐹 moguchart」>「⚙️ 初期設定」をクリック
6. 「設定」シートのB2セルに **APIキー** を入力

### 使い方

| メニュー項目                  | 説明                                           |
| ----------------------------- | ---------------------------------------------- |
| **📋 プロジェクト一覧を取得** | アクセス可能なプロジェクトの一覧をシートに出力 |
| **📊 タスク一覧を取得**       | 選択中のプロジェクトのタスク一覧をシートに出力 |
| **⚙️ 初期設定**               | 設定シートを作成し、APIキーとベースURLを設定   |

### 生成されるシート

- **設定シート** — APIキーとベースURLを管理
- **プロジェクト一覧シート** — プロジェクトID・名前・期間・ロール・表示粒度など
- **タスク一覧シート** — 行名・タスク名・期間・日数・進捗率・ラベル・色・ロック状態・依存関係・説明

> テンプレートの詳細は `docs/gas-template/README.md` を参照してください。

## 20. 公開閲覧モード

公開閲覧モードは、ログインしていないユーザーが一般公開されたプロジェクトのガントチャートを閲覧できる機能です。

### 概要

- プロジェクト設定の「一般公開」をONにしたプロジェクトは、プロジェクトのURL（`https://<ドメイン>/<プロジェクトID>`）に直接アクセスするだけで、ログインなしでガントチャートを閲覧できます
- 公開閲覧モードでは **閲覧者（viewer）** ロールとして動作し、タスク・行・マーカーの編集操作はすべて無効化されます
- テーマ（ライト / ダーク / システム）の切り替えは公開閲覧モード内でも利用可能です（設定はブラウザセッション内のみ有効で、サーバーには保存されません）

### 動作の詳細

| 項目                       | 動作                                                                      |
| -------------------------- | ------------------------------------------------------------------------- |
| **ガントチャートの閲覧**   | ✅ 可能                                                                   |
| **タスク・行の編集**       | ❌ 不可（読み取り専用）                                                   |
| **コメントの閲覧**         | ✅ ツールチップで表示                                                     |
| **コメントの追加**         | ❌ 不可                                                                   |
| **表示設定の変更**         | ✅ テーマ・ズーム・バーの高さなどの表示設定は変更可能（サーバー保存なし） |
| **スナップショットの閲覧** | ❌ 不可                                                                   |
| **エクスポート**           | ❌ 不可                                                                   |
| **コラボレーション**       | ❌ プレゼンス表示・変更履歴は無効                                         |

### 公開閲覧モードの有効化

1. オーナーがプロジェクト詳細ダイアログの **一般タブ** で **「一般公開」** スイッチをONにします
2. プロジェクトのURL（`https://<ドメイン>/<プロジェクトID>`）を共有します
3. URLにアクセスしたユーザーは、ログインなしでガントチャートを閲覧できます

> 一般公開をOFFにすると、ログインしていないユーザーからのアクセスはブロックされます。

### 公開プロジェクト用REST API

公開プロジェクトの情報は、認証不要のREST APIエンドポイントからも取得できます：

| エンドポイント                          | 説明                                         |
| --------------------------------------- | -------------------------------------------- |
| `GET /api/v1/public/projects/:id`       | 公開プロジェクトのプロジェクト情報を取得     |
| `GET /api/v1/public/projects/:id/gantt` | 公開プロジェクトのガントチャートデータを取得 |

> これらのエンドポイントは `X-API-Key` ヘッダーが不要です。対象プロジェクトの「一般公開」がOFFの場合は `403 Forbidden` が返されます。

## 21. サンプルプロジェクトデータ

MoguChartの月単位モードの活用例として、バックアップ復元機能で読み込めるサンプルプロジェクトデータ（JSON形式）を提供しています。

### 提供サンプル一覧

| ファイル名                    | プロジェクト名             | 期間           | 説明                                                                              |
| ----------------------------- | -------------------------- | -------------- | --------------------------------------------------------------------------------- |
| `japan_console_history.json`  | 日本の家庭用ゲーム機の歴史 | 1975年〜2025年 | テレビテニスからNintendo Switchまで、日本の主要な家庭用ゲーム機の販売期間を可視化 |
| `japan_8bit_pc_history.json`  | 日本の8bitパソコンの歴史   | 1978年〜1993年 | PC-8001からMSXまで、日本の代表的な8bitパソコンの販売期間を可視化                  |
| `japan_16bit_pc_history.json` | 日本の16bitパソコンの歴史  | 1982年〜2003年 | PC-9801からFM TOWNSまで、日本の代表的な16bitパソコンの販売期間を可視化            |

### サンプルデータの使い方

1. `docs/samples/` フォルダから利用したいJSONファイルをダウンロードします
2. MoguChartにログインし、プロジェクト一覧ダイアログを開きます
3. **「バックアップ復元」** ボタンをクリックし、ダウンロードしたJSONファイルを選択します
4. プロジェクトが復元され、ガントチャートとして表示されます

> サンプルデータはすべて月単位モードで作成されています。カラーパレット、ラベル、マイルストーンなどの設定例としても参考にできます。
> また、`docs/samples/images/` フォルダには各サンプルプロジェクト（家庭用ゲーム機、8bitパソコン、16bitパソコン）に対応したリファレンス画像が同梱されており、画像添付機能の検証やデモにご活用いただけます。
