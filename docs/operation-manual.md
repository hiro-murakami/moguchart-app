## 1. ログイン・ユーザー設定

### ログイン

- 画面右上の **「Login」** ボタンをクリックして Google アカウントでログインします。
- ログインしないと機能は利用できません。

### ユーザー設定

ログイン後、右上のアバターアイコンをクリックしてメニューを開きます。

| メニュー項目 | 説明 |
|---|---|
| **ユーザー設定** | 表示名の変更ダイアログを開きます |
| **メールアドレス履歴** | 権限設定で使用するメールアドレスの補完候補を管理します |
| **リリースノート** | アプリのリリースノートを表示します |
| **ログアウト** | ログアウトします |

**ユーザー設定ダイアログ** では以下を設定できます：

- **表示名** — 他のユーザーに表示される名前

### メールアドレス履歴

権限設定で入力したメールアドレスは自動的に補完候補として保存されます。**「メールアドレス履歴」** ダイアログでは、保存済みの補完候補を一覧で確認・編集できます。

- 1行に1つのメールアドレスを入力するテキストエリア形式で管理します
- プロジェクト詳細ダイアログの権限タブにある **「メールアドレス履歴を管理」** ボタンからもアクセスできます

## 2. プロジェクト管理

### プロジェクト一覧を開く

- ガントチャート画面上部の **📋（リストアイコン）** をクリック
- または初期画面の **「プロジェクト一覧を開く」** ボタンをクリック

プロジェクト一覧ダイアログは左側に **「メイン」** / **「アーカイブ済」** の縦タブがあり、アーカイブしたプロジェクトと通常のプロジェクトを切り替えて表示できます。

### プロジェクトの検索

- プロジェクト一覧上部の **検索フィールド** にキーワードを入力すると、プロジェクト名・説明文でフィルタリングできます
- マッチした箇所はハイライト表示されます

### プロジェクトの新規作成

1. プロジェクト一覧ダイアログで **「新規作成」** ボタンをクリック
2. プロジェクト詳細ダイアログが開きます
3. 必要な情報を入力して **「OK」** をクリック

### プロジェクト詳細の設定

プロジェクト詳細ダイアログには以下の5つのタブがあります：

#### 一般タブ

| 設定項目 | 説明 |
|---|---|
| **モード** | ガントチャートの粒度を「日単位」または「月単位」から選択（**新規作成時のみ**。作成後は変更不可） |
| **プロジェクト名** | プロジェクトの名前（必須） |
| **説明** | プロジェクトの説明文 |
| **開始日 / 開始月** | ガントチャートの表示開始日（月単位モードでは月選択） |
| **終了日 / 終了月** | ガントチャートの表示終了日（月単位モードでは月選択） |
| **一般公開** | ONにすると全ユーザーが閲覧可能に |
| **変更履歴の自動保存** | 設定した間隔で変更前の状態を自動的にスナップショットとして保存（なし / 5分 〜 24時間） |
| **自動履歴の保持期間** | 自動保存されたスナップショットの保持期間（なし（無期限） / 7日 〜 90日） |

#### 権限タブ

| 権限 | 説明 |
|---|---|
| **オーナー** | プロジェクトに対する全権限を持つユーザー |
| **編集者** | 閲覧・編集権限を持つユーザー |
| **閲覧者** | 閲覧のみ可能なユーザー |

- 権限にメールアドレスを入力する際、過去に入力したメールアドレスが補完候補として表示されます
- 権限タブ下部の **「メールアドレス履歴を管理」** ボタンから補完候補の一覧を編集できます

#### カラーパレットタブ

- タスクバーの色設定に使うカラーパレットを定義します
- **「パレット追加」** でパレットを追加し、**名前**・文字色・背景色を設定できます
- パレット名はタスク編集ダイアログのカラー選択時に表示され、識別しやすい名前を付けることができます
- パレット行をクリックすると詳細設定が展開され、名前の編集や色の変更ができます

#### ラベルタブ

- タスクや**行**に付与できるラベル（タグ）を定義します
- **「ラベル追加」** でラベルを追加し、名前と色を設定できます
- ここで定義したラベルは、タスク編集ダイアログおよび行編集ダイアログから選択できます

#### マイルストーンタブ

- ガントチャート上に縦線とバッジで表示されるマイルストーンを定義します
- **「マイルストーン追加」** でマイルストーンを追加し、名前・日付・色を設定できます
- 設定したマイルストーンはカレンダーヘッダーにバッジ、チャートエリアに縦線として表示されます
- マイルストーンにマウスオーバーすると、対応するバッジと縦線がハイライトされます

### プロジェクト一覧の操作

プロジェクト一覧には **プロジェクト名**・**説明**・**期間**・**モード（日単位 / 月単位）**・**操作** の列が表示されます。

各行には以下のアクションボタンがあります：

**メインタブ（通常表示）：**

| ボタン | 説明 | 必要な権限 |
|---|---|---|
| ✏️ **編集** | プロジェクト詳細の編集 | オーナー |
| 📋 **複製** | プロジェクトのコピーを作成 | 全ロール |
| 📥 **アーカイブ** | プロジェクトをアーカイブ | オーナー |
| 🗑️ **削除** | プロジェクトの削除 | オーナー |
| ⬇️ **ダウンロード** | プロジェクトを ZIP ファイルでダウンロード | 全ロール |

**アーカイブ済タブ：**

| ボタン | 説明 | 必要な権限 |
|---|---|---|
| 📤 **アーカイブから復元** | アーカイブ済みプロジェクトを元に戻す | オーナー |
| 🗑️ **削除** | プロジェクトの完全削除 | オーナー |
| ⬇️ **ダウンロード** | プロジェクトを ZIP ファイルでダウンロード | 全ロール |

> アーカイブしたプロジェクトは「アーカイブ済」タブに移動します。アーカイブ操作後は「元に戻す」スナックバーが表示され、即座にアーカイブを取り消すことも可能です。

### プロジェクトの複製

1. プロジェクト一覧で **📋（複製ボタン）** をクリックすると、「プロジェクト複製」ダイアログがステッパー形式で開きます
2. **ステップ1（プロジェクト名）** — 複製後のプロジェクト名を入力
3. **ステップ2（期間）** — **開始日** を変更すると、元のプロジェクト期間を維持したまま **終了日が自動調整** されます。すべてのタスクとマイルストーンの日付も、開始日の差分に応じて **自動的にスライド** されます
4. **ステップ3（オプション）** — **「進捗率をクリアする」** チェックボックスで、複製後のタスクの進捗率をリセットするかどうかを選択できます（デフォルトはON）
5. **「OK」** をクリックすると、複製が完了し自動的にそのプロジェクトが開かれます

### バックアップからの復元

1. プロジェクト一覧で **「バックアップから復元」** ボタンをクリック
2. JSON ファイルまたは ZIP ファイルを選択
3. 同じ ID のプロジェクトが存在する場合、上書きまたは新規 ID での復元を選択できます

## 3. ガントチャートの基本操作

### 操作マニュアル

- 画面右上の **📖（本アイコン）** をクリックすると、画面右側にドロワー形式で操作マニュアルが表示されます
- ドロワー上部の目次リンクをクリックすると、該当セクションにスクロールします

### ブラウザタブのタイトル

- プロジェクトを開くと、ブラウザのタブタイトルが **「MoguChart - ＜プロジェクト名＞」** に更新されます

### 表示設定メニュー

画面上部右側の **⚙️（設定アイコン）** をクリックすると、表示設定メニューが開きます。

| 設定項目 | 説明 |
|---|---|
| **非表示行を表示** | 非表示設定された行を表示 / 非表示するスイッチ |
| **現在時刻線を表示** | 現在時刻を示す縦線の表示 / 非表示を切り替え |
| **読み取り専用モード** | ONにするとタスク・行の編集操作をすべて無効化します（オーナー / 編集者のみ表示）。プロジェクトごとに保存されます |
| **表示倍率** | ＋ / − ボタンでズームレベルを変更。**日単位モード**: px/日（20px/日 未満になると日付ヘッダーが週番号表示に切り替わります）、**月単位モード**: px/月 |
| **バーの高さ** | 極小 / 小 / 中 / 大 / 特大 から選択（5段階） |
| **テーマ** | ライト / ダーク / システム設定に従う から選択 |

> 設定した表示倍率・バーの高さ・各スイッチの状態はプロジェクトごとにサーバーへ保存され、次回ログイン時にも復元されます。

### データの最新化

- **🔄（リフレッシュアイコン）** をクリックすると、サーバーから最新のデータを取得します

### データのエクスポート（CSV / Excel / 画像 / PDF）

画面上部右側の **📤（エクスポートアイコン）** をクリックすると、エクスポートメニューが表示されます。

| メニュー項目 | 説明 |
|---|---|
| **CSV でエクスポート** | 表示中のデータをCSVファイルとしてダウンロード（BOM付きUTF-8） |
| **Excel でエクスポート** | 表示中のデータをExcelファイル（.xlsx）としてダウンロード |
| **PNG でエクスポート** | ガントチャート全体を画像（PNG）としてダウンロード |
| **PDF でエクスポート** | ガントチャート全体をPDFとしてダウンロード |

エクスポートされるデータ（CSV / Excel）には、以下の列が含まれます：

| 列名 | 説明 |
|---|---|
| **行名** | タスクが所属する行の名前 |
| **タスク名** | タスクの名前 |
| **開始日** | タスクの開始日（YYYY-MM-DD形式） |
| **終了日** | タスクの終了日（YYYY-MM-DD形式） |
| **日数** | タスクの期間（日数） |
| **ラベル** | タスクに付与されたラベル（カンマ区切り） |
| **説明** | タスクの説明文 |

> フィルタやラベルフィルタが適用されている場合は、現在表示されているデータがエクスポート対象になります。

## 4. タスク管理

### タスクの新規作成

1. ガントチャートの空白エリアを **右クリック** してコンテキストメニューを開きます  
2. **「新しいタスクを作成」** を選択
3. タスク編集ダイアログが表示されるので、以下を入力します：
   - **タスク名**（必須）
   - **行**（配置する行）
   - **開始日 / 終了日**
   - **進捗率**（0〜100%、後述）
   - **色設定**（カラーパレットから選択、またはカスタム設定）
   - **ラベル**
   - **説明**
   - **ロック**（後述）
4. **「保存」** をクリック

### タスクの編集

- タスクバーを **ダブルクリック** するとタスク編集ダイアログが開きます
- または、タスクバーを **右クリック** → **「編集」** を選択

### タスクの移動・リサイズ

- タスクバーを **ドラッグ** すると日付を移動できます
- タスクバーの端を **ドラッグ** すると開始日・終了日を変更できます

### タスクの進捗率

タスク編集ダイアログの **「進捗率」** フィールドで、タスクの進捗状況を 0〜100% で入力できます。進捗率はタスクバー上にプログレスバーとして表示されます。

> 進捗率はクリアボタンで未設定（表示なし）に戻すこともできます。

### タスクのロック

タスク編集ダイアログの **「ロック」** スイッチをONにすると、そのタスクの移動・リサイズ・削除がすべて禁止されます。

> ロック中のタスクもダイアログからの編集は引き続き可能です。

### タスクのコピー＆ペースト

1. タスクバーを選択（クリック）した状態で `Cmd+C`（Mac）/ `Ctrl+C`（Windows）でコピー
2. `Cmd+V` / `Ctrl+V` でペースト
3. または、タスクバーを **右クリック** → **「コピー」** でコピー
4. チャートの空白エリアを **右クリック** → **「ペースト」** でペースト

> 複数のタスクを選択してまとめてコピー＆ペーストすることもできます。

### タスクの削除

- タスクバーを **右クリック** → **「削除」** を選択

### タスクの依存関係

- タスクバーの両端に表示される接続ハンドル（丸いアイコン）を **ドラッグ＆ドロップ** して他のタスクに繋ぐことで、タスク間に依存関係の線を作成できます
- 依存関係の線（矢印）を **クリック** するとメニューが表示され、**「依存関係を削除」** を選択すると線を削除できます

### タスクの選択

- タスクバーをクリックすると選択できます
- 複数選択も可能です

## 5. 行の操作

### 行の追加

- チャート左下の **＋（FABボタン）** をクリックすると行追加ダイアログが開きます
  1. **「追加する行数」** に 1〜10 の数値を入力（デフォルトは 1）
  2. **「追加」** ボタンをクリック（または `Enter` キー）
- または、行ヘッダーを **右クリック** → **「上に行を追加」** / **「下に行を追加」** を選択

### 行名のインライン編集

- 行ヘッダーを **Shift+クリック** すると、その場で行名を直接編集できます
- `Enter` で確定、`Esc` でキャンセル

### 行の詳細編集

- 行ヘッダーを **クリック** すると行編集ダイアログが開きます
- または、行ヘッダーを **右クリック** → **「行を編集」** を選択

行編集ダイアログでは以下を設定できます：

| 設定項目 | 説明 |
|---|---|
| **行名** | 行の名前（必須） |
| **ラベル** | 行に付与するラベル（プロジェクトで定義したラベルから選択、複数設定可） |
| **説明** | 行の説明文 |

### 行の並び替え

- 行ヘッダーを **ドラッグ＆ドロップ** して順序を変更できます

### 行の表示/非表示

- 行ヘッダーを **右クリック** → **「行を非表示」** / **「行を表示」** を選択
- 複数の行を選択した状態で操作すると、まとめて表示/非表示を切り替えられます

### 行の削除

- 行ヘッダーを **右クリック** → **「行を削除」** を選択
- 複数の行を選択した状態で操作すると、まとめて削除できます

### 行ヘッダーの幅調整

- 行ヘッダーの右端をドラッグして幅を調整できます

## 6. タスクテンプレート

画面右側のサイドバーからタスクテンプレートを管理できます。

### サイドバーの開閉

- チャートエリア右端の **「タスクテンプレート」** バーをクリックして開閉します
- サイドバーが開いている場合、チャートエリアの右側に幅240pxのパネルが表示されます

### テンプレートの作成

1. サイドバー上部の **＋（プラスアイコン）** をクリック
2. テンプレート名、色、ラベル、説明を設定して保存

### テンプレートからタスクを配置

- サイドバーのテンプレートをガントチャートに **ドラッグ＆ドロップ** するとタスクが作成されます

### テンプレートの編集・削除

- テンプレートを **ダブルクリック** で編集
- テンプレートを **右クリック** → **「編集」** / **「削除」** を選択

---

## 7. 検索・フィルタ

### フリーワード検索

- 画面上部の **「フリーワード検索」** テキストフィールドにキーワードを入力すると、マッチするタスクがハイライトされます
- **「行も検索」** チェックボックスをONにすると、行名も検索対象になります

### ラベルフィルタ（タスク）

- 画面上部の **ラベルフィルタ** アイコンをクリックして、表示するタスクラベルを選択できます
- **「全選択」** / **「全解除」** のショートカットも利用可能です
- フィルタが適用されている場合、対象外のラベルを持つタスクは非表示になります

### 行ラベルフィルタ

- ガントチャート左上の **コーナーメニュー** から行ラベルでフィルタリングできます
- 行にラベルが設定されていない場合はフィルタは表示されません
- 複数のラベルで絞り込むと、選択したラベルのうち**いずれか**が設定されている行が表示されます

## 8. コメント機能

コメントは **タスク**、**行**、**プロジェクト** の3つの対象に対して追加できます。

### タスクへのコメント

- タスクバーを **右クリック** → **「コメント」** を選択するとコメントダイアログが開きます
- コメントが付いているタスクは、コメント件数が表示されます

### 行へのコメント

- 行ヘッダーを **右クリック** → **「行にコメント」** を選択するとコメントダイアログが開きます

### プロジェクトへのコメント（コメントサイドバー）

プロジェクトコメントは、画面右端の **コメントサイドバー** で管理します。

- サイドバーの **タイトルバー** をクリックすると開閉します
- 開いているときのサイドバー幅は右端をドラッグして調整できます（最小220px）
- 開閉状態と幅はプロジェクトごとに保存されます

> チャートエリアはコメントサイドバーの幅に合わせて自動的にリサイズされます。

また、以下のボタンからもコメントダイアログへアクセスできます：

- プロジェクト名の横にある **💬（コメントアイコン）** をクリックするとコメントダイアログが開きます
- コメントがある場合はアイコンの横にコメント件数が表示されます
- コメントアイコンにマウスオーバーすると、直近のコメントがツールチップで表示されます

### コメントダイアログの操作

| 操作 | 説明 | 必要な権限 |
|---|---|---|
| **コメント入力** | テキストエリアにコメントを入力し、送信ボタンまたは `Cmd+Enter` / `Ctrl+Enter` で送信 | オーナー / 編集者 |
| **コメント閲覧** | コメント一覧を閲覧 | 全ロール |
| **コメント削除** | 自分のコメントを削除（オーナーは全コメントを削除可能） | オーナー / 編集者 |

> 閲覧者はコメントの閲覧のみ可能で、コメントの追加・削除はできません。

## 9. スナップショット

### スナップショットの作成

- **📷（カメラアイコン）** をクリックするとスナップショットを作成できます
- スナップショット名（デフォルトは現在の日時）を入力して保存

> 閲覧者にはスナップショット作成ボタンは表示されません。

### スナップショット一覧

- **🖼️（画像アイコン）** をクリックするとスナップショット一覧ダイアログが開きます
- 閲覧者もスナップショット一覧の閲覧は可能です

### スナップショットの操作

一覧の各スナップショットには以下の操作ボタンがあります：

| ボタン | 説明 |
|---|---|
| 📋 **URLをコピー** | スナップショットの閲覧用URLをクリップボードにコピー |
| ⬇️ **ダウンロード** | スナップショットをファイルとしてダウンロード |
| 🔄 **復元** | このスナップショットの状態にプロジェクトを復元 |
| 🗑️ **削除** | スナップショットを削除 |

### スナップショットの閲覧

- スナップショット一覧の行をクリックすると、そのスナップショットを閲覧モードで開きます
- 閲覧中はロールチップに **「スナップショット」** と表示されます

### 自動履歴

- プロジェクト設定で「変更履歴の自動保存」を有効にすると、設定した間隔で変更前の状態が自動的にスナップショットとして保存されます
- 自動保存されたスナップショットは一覧で **🕐（履歴アイコン）** で表示されます

## 10. コラボレーション

### アクティブユーザーの表示

- 同じプロジェクトを開いている他のユーザーが画面上部にアバターで表示されます
- アバターにマウスオーバーすると表示名が確認できます

### 変更履歴パネル

- 画面右下に **「変更履歴」** パネルが表示されます（リアルタイム更新）
- パネルをクリックして展開/折りたたみ可能
- 未読の変更がある場合は赤いバッジに件数が表示されます

#### ログ内のリンク操作

変更履歴パネルでは、各種ログエントリにリンクアイコンが表示され、対象のリソースにアクセスできます：

| ログ種別 | クリック時の動作 | ダブルクリック時の動作 |
|---|---|---|
| **タスクの変更** | タスクにフォーカス（選択状態へ） | タスク編集ダイアログを開く |
| **タスクコメント更新** | タスクにフォーカス（選択状態へ） | コメントダイアログを開く |
| **行コメント更新** | — | コメントダイアログを開く |
| **プロジェクトコメント更新** | — | コメントダイアログを開く |

> ログ内の対象名（タスク名・行名・プロジェクト名）がテキストリンクとして表示されます。リンクアイコンは対象種別に応じて異なります（タスク: 🔗、行: 📊、プロジェクト: 💬）。

## 11. キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Cmd+Z` (Mac) / `Ctrl+Z` (Windows) | **元に戻す（Undo）** |
| `Cmd+Shift+Z` (Mac) / `Ctrl+Y` (Windows) | **やり直し（Redo）** |
| `Cmd+C` (Mac) / `Ctrl+C` (Windows) | **タスクをコピー** |
| `Cmd+V` (Mac) / `Ctrl+V` (Windows) | **タスクをペースト** |
| `Cmd+Enter` / `Ctrl+Enter` | **コメントを送信**（コメントダイアログ内） |

> Undo/Redo はチャートの空白エリアを右クリックしたコンテキストメニューからも実行できます。

## 12. 月単位モード

月単位モードは、プロジェクト作成時に選択する粒度設定です。月をまたぐ長期プロジェクトの管理に適しています。

### 日単位モードとの違い

| 項目 | 日単位モード | 月単位モード |
|---|---|---|
| 開始・終了の設定 | 日付で指定 | 月で指定 |
| タスクの開始・終了設定 | 日付で指定 | 月で指定 |
| 表示倍率の単位 | px/日 | px/月 |
| カレンダーヘッダー | 日・週 | 月・年 |
| プロジェクト複製時の日付スライド | 日単位でスライド | 月単位でスライド |

> モードはプロジェクト新規作成時のみ選択可能で、作成後の変更はできません。
