# MoguChart リリースノート

## v0.11.0

**リリース日: 2026-08-24**

### 新機能

- **ミニマップ（鳥瞰ビュー）機能** — ガントチャート全体を俯瞰できるミニマップコンポーネントを導入しました。タスクやマイルストーンの全体配置を縮小プレビューで一目で把握できます
  - **ビューポートナビゲーション**: ミニマップ内の表示枠（ビューポート）をドラッグまたはクリックすることで、ガントチャートのスクロール位置を素早く移動できます
  - **自由なドラッグ移動**: ミニマップをドラッグして、チャート領域内の見やすい位置へ自由に移動・配置できます
  - **ドラッグリサイズ**: ミニマップの端をドラッグすることで、チャートのアスペクト比を保ったままサイズ（幅・高さ）を自由に変更できます
  - **表示/非表示の切り替え**: 表示設定メニュー（⚙️）の「ミニマップを表示」スイッチから、ミニマップの表示・非表示をいつでも切り替えられます
  - **設定の永続化**: ミニマップの表示状態、幅、表示位置（座標）はプロジェクトごとにサーバーへ自動保存され、次回ログイン・閲覧時にも復元されます

### 改善

- **コアライブラリのアップデート** — `@mogura/moguchart-core` を v0.11.0 へ更新し、リサイズ・ドラッグ移動対応のミニマップ機能との連携および初期化同期・描画制御の安定化を実装しました

### バグ修正

- **PNG/PDFエクスポートの描画不具合を修正** — ガントチャートの画像（PNG）およびPDFエクスポート時に、チャートの中身が描画されず背景色のみが出力されてしまう問題を修正しました（エクスポート時のスクロール位置保持・復元にも対応）

## v0.10.0

**リリース日: 2026-08-23**

### 新機能

- **行の入れ替え禁止設定** — プロジェクト詳細ダイアログに「編集オプション」タブを追加し、「行の入れ替えを禁止する」設定を導入しました。ONにすると、ドラッグ＆ドロップによる行の並べ替え操作が無効化され、行の順序が意図せず変更されるのを防止できます
- **タスク移動の横方向限定設定** — 「編集オプション」タブに「タスクの移動を横方向に限定する」設定を導入しました。ONにすると、タスクバーを上下にドラッグして別の行へ移動する操作が無効化され、同一行内での日付移動のみに制限できます
- **ドラッグ操作の領域外キャンセル対応** — タスクバーのドラッグ（移動・リサイズ・行間移動）中にマウスポインターがガントチャート領域外に出た場合、ドラッグ操作が安全にキャンセルされ、元の位置に戻るようになりました

### 改善

- **プロジェクト詳細ダイアログのUIレイアウト最適化** — 「編集オプション」タブの新設に伴いタブ構成を整理し、ダイアログ内のレイアウトやヘルプテキストの配置を見直しました。また、カラーパレット、ラベル、マイルストーンの一覧表示領域の高さを拡張（最大560px）し、多数の項目がある場合でもより広々と編集できるようになりました
- **コアライブラリのアップデート** — `@mogura/moguchart-core` を v0.10.0 へ更新し、行間移動の制御オプション（`enableCrossRowMove`）やドラッグキャンセル処理の連携を強化しました

### 新機能

- **タスク画像管理** — タスクに画像を添付できるようになりました。タスクバーを右クリック → **「画像」** から画像管理ダイアログを開き、Firebase Storageに画像をアップロード・管理できます。登録した画像はガントチャート上でタスクバーにマウスオーバーするとポップアップでプレビュー表示され、クリックするとライトボックスで拡大表示されます。複数画像の場合はナビゲーションボタンと左右キーで画像を切り替えられます

- **タスク・行削除時の画像自動削除** — タスクや行を削除した際に、関連付けられた画像がFirebase Storageから自動的に削除されるようになりました。不要な画像が残り続けることを防ぎます
- **サンプルプロジェクトに画像データを追加** — 「日本の家庭用ゲーム機の歴史」サンプルプロジェクトに各ゲーム機の画像を追加しました。画像機能の活用例として参考にできます

## v0.7.1

**リリース日: 2026-06-26**

### 新機能

- **公開プロジェクトの閲覧モード** — プロジェクト設定で「一般公開」をONにしたプロジェクトは、ログインしていないユーザーでもプロジェクトのURLに直接アクセスするだけでガントチャートを閲覧できるようになりました。公開閲覧モードでは閲覧者（viewer）ロールとして動作し、編集操作は無効化されます。テーマ（ライト / ダーク / システム）の切り替えも公開閲覧モード内で利用できます
- **公開プロジェクト用REST APIエンドポイント** — 認証不要で公開プロジェクトの情報とガントチャートデータを取得できるREST APIエンドポイント（`GET /api/v1/public/projects/:id`、`GET /api/v1/public/projects/:id/gantt`）を追加しました
- **APIキー管理UI** — ユーザーメニューの「APIキー管理」からブラウザ上でREST API用のAPIキーを管理できるようになりました。キーの新規作成（名前・スコープ指定）、一覧表示（マスク済みキー・最終使用日時・状態）、無効化の操作が可能です。作成直後にはフルキーが表示され、クリップボードへのコピーにも対応しています
- **REST APIレートリミット** — REST APIにAPIキー単位のレートリミット（1分あたり60リクエスト）を導入しました。スライディングウィンドウカウンターアルゴリズムにより滑らかなレート制御を実現しています。レートリミットの状態はレスポンスヘッダー（`RateLimit-Limit`、`RateLimit-Remaining`、`RateLimit-Reset`）で確認できます。制限を超過すると `429 Too Many Requests` が返され、`Retry-After` ヘッダーで待機時間が通知されます。ヘルスチェック（`/api/v1/health`）および公開プロジェクト用エンドポイントにはレートリミットは適用されません

### 改善

- **ラベルフィルタの候補をデータから自動収集** — タスクラベルフィルタおよび行ラベルフィルタの候補を、プロジェクト設定のラベル定義からではなく、実際のタスクや行に付与されたラベルから自動的に収集するようになりました。未使用のラベルがフィルタ候補に表示されなくなり、より直感的に操作できます
- **ツールチップの自動位置調整** — タスクバーや行ヘッダーのツールチップ（コメントプレビュー等）が画面端からはみ出す場合に、表示位置を自動的に調整して画面内に収まるようになりました
- **月単位モードの期間上限を拡大** — 月単位モードで設定可能なプロジェクト期間の上限を30年から **100年** に拡大しました。年表や歴史的なタイムラインなど、より長期にわたるプロジェクトの管理が可能になりました
- **月単位モードのズーム範囲を拡大** — 月単位モードの表示倍率の最小値を 20px/月 から 10px/月 に変更し、より広い期間を俯瞰的に表示できるようになりました
- **レートリミットデータの自動クリーンアップ** — 24時間以上更新されていないレートリミットデータを6時間ごとに自動削除するスケジュール関数を追加しました
- **サンプルプロジェクトデータを追加** — バックアップ復元機能で利用できるサンプルプロジェクトデータ（JSON形式）を `docs/samples/` に追加しました。月単位モードのガントチャートの活用例として、「日本の家庭用ゲーム機の歴史」「日本の8bitパソコンの歴史」「日本の16bitパソコンの歴史」の3つのサンプルを提供しています

- **OpenAPI仕様書** — REST APIのOpenAPI 3.1仕様書（`docs/openapi.yaml`）を追加しました
- **行ヘッダーのツールチップ** — ガントチャートの行ヘッダーにマウスオーバーすると、行の説明・ラベル・タスク数・コメント数をツールチップで確認できるようになりました

### 改善

- **マーカー編集ダイアログの破棄確認** — マーカー編集ダイアログで未保存の変更がある状態でダイアログを閉じようとすると、変更を破棄するかどうかの確認ダイアログが表示されるようになりました
- **マーカーのデフォルト設定を変更** — マーカー新規作成時のデフォルトスタイルプリセットとフォントサイズを最適化しました
- **プロジェクト復元のUUID検証を強化** — バックアップ復元時にプロジェクトIDのUUID形式を検証し、非UUID形式のIDの場合は自動的にUUIDを生成するようになりました

## v0.6.9

**リリース日: 2026-06-14**

### 新機能

- **マーカー管理機能** — ガントチャートの行上にマーカー（シンボル付きの目印）を配置できるようになりました。マイルストーンとは異なり、行ごとに個別の日時を指定してピンポイントで配置できます
  - チャートの空白エリアを右クリック → **「新規マーカー」** で作成

  - フォントサイズ（極小 / 小 / 中 / 大 / 特大）でラベルとシンボルの大きさを調整可能
  - プリセットカラーまたはカスタム色で色を設定可能
  - 編集中のマーカーにはパルスアニメーションとグローエフェクトが適用され、対象が視覚的にわかる

- **バックエンドのクリーンアップ処理を強化** — コラボレーション機能で使用するプレゼンスデータと編集イベントデータの自動クリーンアップ処理を追加しました。一定時間経過した古いデータが定期的に削除され、データベースの肥大化を防ぎます
