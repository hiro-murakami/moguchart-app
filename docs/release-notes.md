## v0.6.2

**リリース日: 2026-05-06**

### バグ修正

- **Mac での Ctrl+ドラッグ時にコンテキストメニューが表示される問題を修正** — Mac 環境でタスクバーを `Ctrl+ドラッグ` してコピー操作を開始しようとした際に、コンテキストメニューが誤って表示されてしまう問題を修正しました

### 改善

- **バーの影設定の後方互換性を追加** — v0.6.1 で追加したバーの影段階設定（`barShadowLevel`）について、旧フォーマット（`showBarShadow: boolean`）で保存されている設定からの自動移行処理を追加しました。既存の設定（表示あり → 「中」、表示なし → 「なし」）を正しく引き継ぎます

## v0.6.1

**リリース日: 2026-05-06**

### 新機能

- **カラーパレットにパターン設定を追加** — プロジェクト詳細のカラーパレットタブで、タスクバーの背景にストライプなどのパターンを設定できるようになりました。パレット行をクリックして詳細を展開し、「パターンタイプ」と「パターン色」を設定します
- **カラーパレットに枠線設定を追加** — カラーパレットの詳細設定で、タスクバーの枠線タイプ（実線・破線・点線、細・太）と枠線色を設定できるようになりました
- **バーの影設定を追加** — 表示設定メニューに「バーの影」オプションを追加しました。タスクバーのドロップシャドウの強さを「なし / 小 / 中 / 大」の4段階で調整できます（デフォルトは「中」）。設定はプロジェクトごとに保存されます

---

## v0.6.0

**リリース日: 2026-05-05**

### 新機能

- **時間単位モード** — プロジェクト作成時にガントチャートの粒度を「時間単位」から選択できるようになりました。時間単位プロジェクトでは開始日時・終了日時を分単位で設定し、タスクの日付も日時で管理できます。カレンダーヘッダーは「時間・日」形式で表示されます。モードは作成時のみ設定可能で、作成後の変更はできません
- **スナップ単位の設定** — 時間単位モードのプロジェクトでは、タスクの移動・リサイズ時にスナップする時間の刻みをプロジェクト詳細ダイアログで設定できます（60 / 30 / 15 / 12 / 6 / 5分から選択、デフォルトは60分）
- **月単位モード** — プロジェクト作成時にガントチャートの粒度を「月単位」から選択できるようになりました。月単位プロジェクトでは開始月・終了月を月単位で設定し、タスクの日付も月単位で管理できます。モードは作成時のみ設定可能で、作成後の変更はできません
- **プロジェクト一覧にモード列を追加** — プロジェクト一覧にモード（時間単位 / 日単位 / 月単位）を示すチップが表示されるようになりました
- **行ラベル機能** — 行に対してプロジェクトで定義したラベルを設定できるようになりました。行編集ダイアログでラベルを追加・管理できます
- **行ラベルフィルタ** — ガントチャートのコーナーメニュー（左上）から行ラベルでフィルタリングできるようになりました
- **カラーパレットに名前を設定** — プロジェクト詳細のカラーパレットタブで、各パレットに名前を設定できるようになりました。名前はタスク編集ダイアログのカラー選択時に表示されます

### 改善

- **タスクラベルの表示位置変更** — タスクのラベルがガントチャートのバー上からタスク名行に移動しました
- **行ヘッダーのクリック操作変更** — 行ヘッダーをクリックすると行編集ダイアログが開くようになりました。インライン行名編集は **Shift+クリック** で行います

## v0.5.6

**リリース日: 2026-05-02**

### 新機能

- **テーマ設定を表示設定メニューに統合** — テーマ（ライト / ダーク / システム）の切り替えがユーザー設定ダイアログから表示設定メニューに移動しました。チャートを開いたままテーマをすぐに変更できます
- **バーの高さに「極小」を追加** — バーの高さのオプションが「小 / 中 / 大 / 特大」の4段階から「極小 / 小 / 中 / 大 / 特大」の5段階になりました
- **リリースノートの自動表示** — バージョンアップ後の初回ログイン時にリリースノートが自動的に表示されるようになりました
- **読み取り専用モード** — 表示設定メニューに「読み取り専用モード」スイッチを追加しました。ONにするとタスク・行の編集操作をすべて無効化でき、閲覧専用として使用できます（オーナー・編集者のみ利用可能、設定はプロジェクトごとに保存）

### バグ修正

- 現在時刻がガントチャートの表示期間外の場合に時刻線が描画され、横スクロール幅が意図せず広がってしまう問題を修正。期間外は時刻線・バッジを非表示にするようにしました
