# MoguChart リリースノート

---

## v0.5.6

**リリース日: 2026-05-02**

### 新機能

- **テーマ設定を表示設定メニューに統合** — テーマ（ライト / ダーク / システム）の切り替えがユーザー設定ダイアログから表示設定メニューに移動しました。チャートを開いたままテーマをすぐに変更できます
- **バーの高さに「極小」を追加** — バーの高さのオプションが「小 / 中 / 大 / 特大」の4段階から「極小 / 小 / 中 / 大 / 特大」の5段階になりました
- **リリースノートの自動表示** — バージョンアップ後の初回ログイン時にリリースノートが自動的に表示されるようになりました
- **読み取り専用モード** — 表示設定メニューに「読み取り専用モード」スイッチを追加しました。ONにするとタスク・行の編集操作をすべて無効化でき、閲覧専用として使用できます（オーナー・編集者のみ利用可能、設定はプロジェクトごとに保存）

### バグ修正

- 現在時刻がガントチャートの表示期間外の場合に時刻線が描画され、横スクロール幅が意図せず広がってしまう問題を修正。期間外は時刻線・バッジを非表示にするようにしました

## v0.5.5

**リリース日: 2026-04-29**

### 新機能

- **PDFエクスポート** — ガントチャート全体をPDFとしてダウンロードできるようになりました
- **タスクの依存関係** — タスク間に依存関係の矢印線を作成できるようになりました。タスクバー両端のハンドルをドラッグして他のタスクに繋ぐことで設定できます
- **リリースノート表示** — アバターアイコンのメニューから本リリースノートを確認できるようになりました

## v0.5.4

**リリース日: 2025-04-10**

### 新機能

- **プロジェクト複製の強化** — 複製時に進捗率をクリアするオプションを追加しました
- **マイルストーンのハイライト** — マイルストーンにマウスオーバーすると、対応するバッジと縦線がハイライトされるようになりました

### 改善

- プロジェクト一覧の検索機能を改善（マッチ箇所のハイライト表示）
- スナップショット一覧のUI改善

### バグ修正

- アーカイブ済みプロジェクトが一覧に表示されないことがある問題を修正

## v0.5.3

**リリース日: 2025-03-20**

### 新機能

- **変更履歴の自動保存** — プロジェクト設定で自動スナップショットの間隔と保持期間を設定できるようになりました
- **コメントサイドバー** — プロジェクトコメントを画面右端のサイドバーで管理できるようになりました

### 改善

- 行ヘッダーの幅調整が可能になりました
- タスクのコピー＆ペーストで複数選択に対応しました

### バグ修正

- Undo/Redo 実行時に変更履歴パネルが正しく更新されない問題を修正

### 新機能

- **タスクの依存関係** — タスク間に依存関係の矢印線を作成できるようになりました

- ズームレベル変更後にスクロール位置がずれる問題を修正
